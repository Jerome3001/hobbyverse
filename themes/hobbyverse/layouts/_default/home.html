Pour débuter

Par où commencer, hobby par hobby

Ton premier Gunpla

  1. Tout débutant : l'Entry Grade (EG) se monte sans outils ni colle. Sinon, le High Grade (HG) au 1/144 est le choix classique.
  2. Pour un HG, prends une pince coupante plutôt que les doigts pour détacher les pièces.
  3. Pour un rendu propre, retire les traces des attaches au cutter avant d'assembler.
{{ with .Site.GetPage "/blog/gunpla-quel-grade-choisir-pour-debuter" }}Lire le guide des grades{{ end }}

Ton premier set LEGO

  1. Choisis un thème qui te parle plutôt qu'une taille impressionnante.
  2. Respecte les sachets numérotés : ils suivent les étapes de la notice.
  3. Utilise l'app LEGO Builder pour voir le modèle en 3D, le zoomer et le faire pivoter.
{{ with .Site.GetPage "/blog/meilleur-lego-pour-adulte" }}Lire le guide des sets{{ end }}

Ta première collection de cartes

  1. Choisis un seul jeu : Pokémon, Magic, Lorcana...
  2. Démarre avec un deck préconstruit pour apprendre les règles.
  3. Protège tes cartes avec des sleeves dès le départ.
